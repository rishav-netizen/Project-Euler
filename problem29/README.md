## 📜 Problem Statement

How many distinct terms are in the sequence generated by $a^b$ for $2 \le a \le 100$ and $2 \le b \le 100$?

🔗 **Project Euler Link:** [Problem 29](https://projecteuler.net/problem=29)

---

## 💡 Key Learnings & Mathematical Insights

- **Set Deduplication**: Collect $a^b$ in a hash set to eliminate collisions (e.g. $4^2 = 2^4$).
- **Scale**: $99 \times 99 = 9801$ total pairs, calculated in <10 ms in Python.
